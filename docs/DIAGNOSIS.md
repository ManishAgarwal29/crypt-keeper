# Does the autopsy name the cause?

Generated by `scripts/diagnosis_check.py report`. This is a different question from the benchmark: for the dead packages in the final held-out list, did the **static** autopsy (the Coroner; nothing is executed) name why they are dead?

**It named the cause for 10 of 19 packages.**

| Cause (hand-read) | Autopsy named it |
|---|---|
| Python 2 code | 8 of 8 |
| A dependency removed a name the package uses | 0 of 5 |
| Imports something it never declares | 0 of 4 |
| A declared dependency could not be installed from a wheel | 2 of 2 |

## How a match is decided

- **Python 2 code:** the autopsy reports a `syntax-error` finding (the source does not parse as Python 3).
- **Every other cause:** a finding's message must name the dependency or module that broke the package (a whole-word match). A file path does not count, and neither does the age finding.

## Where the autopsy saw more than the hand reading

The hand reading records the first failure each package hit when it ran. For these packages the autopsy also found Python 2 syntax, which the first failure did not show: minimongo, Pylons. Fixing the named cause would not have been enough.


## What this does and does not show

- The causes were labelled by the author from the recorded failures, so they are not an independent ground truth.
- The matching rule was written after the autopsy output had been read. Treat the totals as indicative, not as a clean measurement.
- For the packages whose dependency could not be installed, "named" means the autopsy flagged that dependency as old or hard-pinned. It did not predict that the install would fail.
- 19 packages, one list, one day. The Coroner has tables for Python 2 syntax and removed standard-library APIs; it has none for names a third-party dependency removed, and it does not look for imports a package forgot to declare. The totals reflect that.
- When a package is run, the proof-of-life error names the exact failing import for every one of these. That is observed, not predicted, and it is where the hand-read causes came from.
