# Fifth benchmark set, written AFTER the levers were finished (Python 2 conversion, removed-name ceilings, declared
# imports, the unittest._TextTestResult rename) and BEFORE they were run on anything here. Never run through Crypt Keeper.
#
# Why a fifth list: the fourth list found two flaws in the Python 2 conversion (it fired on stray Python 2 files in tests
# and examples, and it accepted output that parses but does not compile) and showed which libraries old packages forget
# to declare. Those were fixed and added, so the fourth list is now a development result. This list is the clean one for
# the final code: the code is not changed after it is run.
#
# Picked from memory as "old packages in families the earlier lists did not use": data validation and configuration,
# filesystem and process tools, scraping and text, media, email and social APIs, caches, crypto, packaging tools, the
# IPython-era support libraries and older test plugins. I did not look at their code or at how the tool does on them.
#
# The same written rule applies, and scripts/benchmark.py applies it, not me:
#   * the latest release was uploaded before 2021-01-01, and
#   * it has an sdist, and
#   * at most 42 held-out packages are run: the first 42 that pass, in this order.
#
# Every candidate is recorded, including the ones the rule excludes. Names that PyPI does not know are excluded.
