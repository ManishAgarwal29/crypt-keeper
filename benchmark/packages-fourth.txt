# changes were run on anything, and never run through Crypt Keeper before.
#
# Why a fourth list: the three earlier lists are where those three changes came from (their failures were read to
# decide what to build), so a result on them is a development result. These were picked from memory as "old packages
# in families the earlier lists did not use": command-line and text utilities, dates, testing tools, small web
# frameworks, old database layers, async and RPC libraries, devops tools, small domain libraries, old astronomy
# tools. I did not look at their code, and I did not look at how the tool does on them.
#
# The same written rule applies, and scripts/benchmark.py applies it, not me:
#   * the latest release was uploaded before 2021-01-01, and
#   * it has an sdist, and
#   * at most 42 held-out packages are run: the first 42 that pass, in this order.
#
# Every candidate is recorded, including the ones the rule excludes. Names that PyPI does not know are excluded.
